The shell includes it for the owner and guests only: a stranger never meets it. - It shows only when the browser offers an install (`beforeinstallprompt`), or on an iPhone/iPad in Safari (no such event there: the bar says Share, then Add to Home Screen, and has no Install button), 4 s after the page came. Never inside the installed app. - ✕ puts it away for 14 days, then 60; after the third ✕, or an install, it is gone for good. State in localStorage['pypenInstallNudge']. - One offer, one prompt(): the event is window.__installEvt, which the Settings page hands to the kit's Install row (kitSettings.offer); a tap on either lets go of it in both (kitSettings.offer(null) here, the Settings page clears __installEvt and hides the bar). - The kit's "New version ready" toast hides it while it shows (html.kit-update-on #installbar, in _update.html); the kit's toast does too (app.css), so the two never sit on each other. - Lives outside #main, so a boosted navigation keeps it. htmx's history restore rewrites from a snapshot: the clicks are delegated and the bar is set again after a restore. - ?installdemo=1 shows it at once, whatever the state (screenshots, tests). {% endcomment %}
