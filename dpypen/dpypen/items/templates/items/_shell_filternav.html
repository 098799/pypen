{% comment %} Filter controls that sit outside the region htmx swaps — the view toggle, the sort select, the rotation chips — keep whatever URL the server gave them at first render. Type a search and they still point at the pre-search URL, so switching view or sort silently threw the search away, and the rotation chips' pressed state never moved off "All". Rebuilding each control's URL from the live query string means it can only ever set or clear its own key, and the pressed state follows from the same comparison. Done in place rather than by re-rendering, so a horizontally scrolled bar keeps its scroll position. {% endcomment %}
